# 第 1—3 天真机验收

## 1. 验收环境

必须具备：

- macOS 与最新稳定版 Xcode（使用 iOS 26 SDK 或更高版本）；
- XcodeGen；
- 已加入 Apple Developer Program 的团队；
- 一台开启“屏幕使用时间”的真实 iPhone；
- iPhone 已安装抖音；
- 主 App、3 个扩展和 App Group 均完成开发签名配置。

不要用模拟器给出通过结论。测试期间建议保持 iPhone 自动日期、时间和时区开启。

## 2. 首次构建

1. 在项目根目录执行 `./scripts/bootstrap-ios.sh`。
2. 在 Xcode 打开 `PauseNow.xcodeproj`。
3. 为 4 个 target 选择同一个 Team。
4. 检查主 App 和扩展的 Bundle ID 与开发者后台一致。
5. 检查 App Group 为 `group.com.pausenow.shared`。
6. 检查 4 个 target 都具备 Family Controls capability。
7. 选择真实 iPhone，Build and Run。
8. 若 Xcode 自动修改签名配置，只提交有意的工程变更；不要删除 entitlement 来绕过签名错误。

## 3. 用例 A：申请授权

**前置**：首次安装，或已在系统设置中撤销 PauseNow 的屏幕使用时间权限。

1. 打开 PauseNow。
2. 点击“申请个人设备授权”。
3. 在系统弹窗中同意。

**通过标准**：

- 验证面板显示“已授权”；
- App 无崩溃；
- 系统设置中可看到 PauseNow 的屏幕使用时间访问状态。

**证据**：授权后状态截图；设备型号、iOS 版本和构建号。

## 4. 用例 B：选择抖音

1. 点击“打开系统应用选择器”。
2. 仅勾选抖音，不选择类别或网站。
3. 返回主 App。
4. 强制关闭并重新打开 PauseNow。

**通过标准**：

- 面板显示“已选应用令牌 1”；
- 重启 App 后仍显示 1；
- 工程未展示或记录抖音的 Bundle ID/名称。

**证据**：系统选择器勾选截图；重启后的令牌数量截图。

## 5. 用例 C：指定时间屏蔽

1. 点击“停止监控并解除所有屏蔽”。
2. 把开始时间设为当前时间后 2 分钟，结束时间设为开始后 3 分钟。
3. 点击“登记一次性屏蔽时段”。
4. 强制关闭 PauseNow。
5. 开始时间前确认抖音可打开。
6. 到开始时间后打开抖音。
7. 到结束时间后再次打开抖音。

**通过标准**：

- 开始前不屏蔽；
- 开始后出现自定义 Shield；
- 重新打开 PauseNow 并刷新记录，可看到“定时时段开始”；
- 结束后 Shield 解除，记录出现“定时时段结束”。

**证据**：三阶段录屏；两条扩展记录截图。

## 6. 用例 D：使用阈值屏蔽

1. 点击“停止监控并解除所有屏蔽”。
2. 点击“登记 1 分钟使用阈值”。
3. 立即打开抖音，持续前台使用至少 70 秒。
4. 若 Shield 未立即出现，退出并重新打开抖音。
5. 返回 PauseNow 刷新回调记录。

**通过标准**：

- 登记前的历史用量不应直接计入；
- 本轮累计使用约 1 分钟后出现 Shield；
- 记录出现“达到使用阈值”。

**证据**：从登记到拦截的连续录屏；回调记录；实际触发耗时。

**异常分支**：若登记后数秒内立即触发，先撤销并重新授予屏幕使用时间权限后复测；仍复现则记录 iOS 版本与 sysdiagnose，不判定通过。

## 7. 用例 E：自定义 Shield

1. 点击“停止监控并解除所有屏蔽”。
2. 点击“立即屏蔽所选应用（测试）”。
3. 打开抖音。

**通过标准**：

- 页面标题为“停一下”；
- 显示暂停图标和自定义说明；
- 主按钮为“临时解锁 1 分钟”；
- 次按钮为“先不打开”；
- 点击次按钮后目标 App 关闭。

**证据**：Shield 全屏截图；次按钮操作录屏。

## 8. 用例 F：按钮临时解除并重新屏蔽

1. 保持用例 E 的 Shield 状态。
2. 点击“临时解锁 1 分钟”。
3. 确认可以进入抖音。
4. 持续前台使用至少 70 秒。
5. 返回 PauseNow 刷新回调记录。

**通过标准**：

- 点击主按钮后可进入目标 App；
- 记录出现“Shield 主按钮：临时解锁 1 分钟”；
- 累计再使用约 1 分钟后重新出现 Shield；
- 记录出现“临时解锁额度用尽”。

**证据**：从点击主按钮到再次拦截的连续录屏；两条回调记录。

## 9. 清理与回归

每次测试结束必须：

1. 打开 PauseNow；
2. 点击“停止监控并解除所有屏蔽”；
3. 确认面板中的已登记监控为“无”；
4. 确认抖音恢复可用。

额外回归：重启 iPhone 后分别重跑用例 C、D；在主 App 被强制关闭时验证系统仍能唤醒扩展。
